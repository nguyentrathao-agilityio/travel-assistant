# CopilotKit Training

A hands-on training repository for learning [CopilotKit](https://docs.copilotkit.ai/) — an open-source framework for building AI copilots into React applications.

## About

This repo contains exercises, examples, and notes from working through CopilotKit's core features, including:

- `useCopilotReadable` — exposing app state to the AI
- `useCopilotAction` — letting the AI trigger actions in your UI
- `CopilotTextarea` — AI-assisted text input
- `CopilotChat` / `CopilotSidebar` — drop-in chat UI components
- `CopilotTask` — running background AI tasks

## Prerequisites

- Node.js 18+
- A CopilotKit API key (or a self-hosted LLM backend)
